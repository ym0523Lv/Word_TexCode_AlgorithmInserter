# Word_TexCode_AlgorithmInserter
## 这是在word里以表格形式插入类似latex格式算法代码块的插件。

## 使用方法如下：
1. 下载 **manifest.xml**
2. 在电脑任意位置（比如 D 盘）新建一个文件夹，命名为 **WordPlugins**，把 **manifest.xml** 放进去。
3. 右键这个 WordPlugins 文件夹 -> 属性 -> 共享 -> 高级共享 -> 勾选“共享此文件夹” -> 点击确定。
4. 打开 Word，点击 文件 -> 选项 -> 信任中心 -> 信任中心设置 -> 受信任的加载项目录。
5. 在“受信任的加载项目录”路径里，输入刚才共享文件夹的网络路径（比如 \\电脑名字\WordPlugins），点击“添加加载项目录”，勾选“在菜单中显示”，点确定。
6. 重启 Word。
7. 点击顶部的 插入（也有可能是 开始） -> 获取加载项 -> 共享文件夹，这个“插件”就在里面，点击添加即可使用。
